Questions
Is this a subscription?

No. MoneyForge is a one-time purchase. The only recurring charge is optional — a $29/mo add-on if you want extra seats on one license.

Does my data go to the cloud?

Generation happens entirely on your own machine. The only network calls are optional cloud add-ons (premium captions, premium voices) — never required to use the app.

What GPU do I actually need?

12GB of VRAM is the recommended baseline — an RTX 3060 12GB or better. 6GB is enough for image generation alone, but video and music-video generation need the full 12GB.

Can I clone my own voice for narration?

Yes — for free, entirely locally, no account required. An ElevenLabs connection is also supported if you want cloud-grade voice quality instead.

Which platforms can it post to?

YouTube, TikTok, Instagram, Facebook, Pinterest, and X — captioned per-platform and posted automatically, on a schedule you set.
