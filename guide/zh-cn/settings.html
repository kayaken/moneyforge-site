设置与疑难排解

密钥、授权、备份，以及最常遇到的问题的解决方法。

Settings（设置）

  • License（授权）：Activate 激活密钥；换到新电脑前，先点击 Deactivate this machine。
  • Change password：修改 MoneyForge 登录密码。
  • Google Gemini API Key（可选）：更好的图片评分、多角色一致性、脚本、翻译，以及定时发布系列的安全检查。自动设置下载的免费本地 AI 模型不需密钥即可处理大部分项目。加入密钥后，相关内容会发送到 Google。
  • ElevenLabs API Key（可选）：自然语音、声音库与声音克隆。请见声音。
  • Data & Backup（数据与备份）：Backup now、Show in folder、Restore。
  • Trash（垃圾桶）：Restore all（全部还原）或 Empty trash permanently（永久清空）。
  • System（系统）：版本号与 Run system check（运行系统检查）。

程序内的 Help 页面也会回答最常见的问题。

疑难排解

出现“No GPU detected”或一切都非常慢

更新 NVIDIA 驱动程序并重启电脑，再打开 Setup。若 Setup 仍显示没有显卡，请点击 Copy system info 并发送给客服。

视频、电影或 AI MV 一开始就失败

检查 Setup → Model files：视频模型（约 64 GB）必须完整下载。只有 12 GB 以上的显卡才会下载视频模型。

某个选项无法勾选（灰色）

背景音乐、音效、视频素材和白板选项，需要对应的素材库至少有一个项目。有锁头图标的选项需要 Pro。

“Generate script”显示没有设置 AI 文本服务

本地 AI 文本模型尚未下载完成。请在 Setup 页面查看进度，或在 Settings 加入免费的 Gemini 密钥。

Reel 被拒绝，显示“reels need an AI text check”

原因相同：本地 AI 文本模型尚未就绪。请让它在 Setup 页面下载完成（若已关闭自动设置，请展开 Manual setup 并使用 Install local AI model server），或在 Settings 加入免费的 Gemini 密钥。

旁白听起来像机器人

那是 Windows 系统语音。没有设置 ElevenLabs 密钥，或所选的 ElevenLabs 声音无法使用时，就会改用系统语音。请在 Settings 加入密钥。

电影比我设置的短

每个电影任务最多制作 6 个 5 秒场景（约 30 秒）。请见制作较长的视频。

无法登录

新安装时请使用 admin / moneyforge，或点 reset it 链接。Gumroad 的账号密码在这里无法使用。尝试太多次后，请等 15 分钟或重启电脑。

联系客服

请发送邮件至 support@moneyforgestudio.com（可用中文），附上 Setup → Copy system info 的内容，并简单说明您做了什么、发生了什么。也可以使用客服页面上的在线对话。
