声音

声音与声音克隆

免费的系统语音可直接使用。想要自然的声音或克隆自己的声音，请加入 ElevenLabs 密钥。

免费的 Windows 系统语音

打开 Voices，在 Your Windows system voices (free, offline) 对任一语音点击 + Add。Windows 可在“设置 → 时间与语言 → 语音 → 添加语音”加入更多语音，包括中文语音。

加入 ElevenLabs 密钥

ElevenLabs 是另外付费的语音服务。自然语音、声音库与声音克隆都使用您自己的 ElevenLabs 账号。

  1. 到 elevenlabs.io 注册账号，在 ElevenLabs 的设置中复制 API 密钥。
  2. 在 MoneyForge 打开 Settings → ElevenLabs API Key，粘贴后点击 Save key。

设置密钥后，旁白文本（以及您上传的声音样本）会发送到 ElevenLabs 处理。

浏览 ElevenLabs 声音库

在 Voices 页面，Browse ElevenLabs voice library 可搜索数千种社区声音，并按性别、年龄、口音筛选。点击 + Add 即可使用，不需要录音。

克隆自己的声音

声音克隆需要 ElevenLabs Starter 套餐以上。

  1. 录制 1 到 2 分钟自然说话的声音：安静的房间，没有音乐或回音，手机或耳机麦克风靠近嘴巴。保存为 .mp3 或 .wav。
  2. 在 Voices 页面的 Clone a new voice，输入 Name（名称）。
  3. Voice engine：选择 ElevenLabs。
  4. Audio samples：选择您的录音文件（可选多个文件）。
  5. Whose voice is this?：确认这是您自己的声音，或已获得说话者的同意。每次都必须确认；未经同意克隆他人声音在许多地区是违法的。
  6. 创建声音。它会出现在列表中，以及 Create 页面所有的 Voice 菜单里。

使用方式：在 Reel 的 Voice 选择它，或把它设为角色的 Default voice。中文旁白请在 Narration language 选择 Chinese。

1.0.3 版

1.0.3 版的安装程序尚未提供免费的本地声音克隆（不需 ElevenLabs），选项会显示“not available in this version yet”。目前请使用 ElevenLabs 进行声音克隆。
