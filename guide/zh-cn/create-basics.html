开始制作

Create 基础

所有图片、视频、电影、音乐 MV 和 Reel 都从 Create 页面开始。基本控制项共用，每种媒体类型再加上各自的设置卡。

步骤 1：选择模板或从头开始

Create 页面一开始会显示 Featured templates（精选模板），可用分页筛选（All、Images、Videos、Music Videos、Movies、Reels）。模板会自动填入媒体类型、风格，有时也会固定画面比例（例如“Fixed 9:16 … Required by this template”）。点击 ✦ Start from scratch 可自行设置所有项目。

步骤 2：设置面板

设置用途
Media type（媒体类型）Image、Video、Movie、Music video 或 Reel。本手册每一种都有独立章节说明。
Aspect ratio（画面比例）16:9（YouTube）、9:16（TikTok、Reels、Shorts）、1:1、4:5、3:4、2:3、3:2、4:3。
Image quality（图片画质）适用于图片、Reel 与歌词卡片 MV：720p、1080p（默认）、2K、4K、8K。4K 与 8K 会在生成后放大到该尺寸，需要 Pro。
Video quality（视频画质）适用于视频、电影与 AI MV：480p（默认）或 720p。720p 需要 Pro，可用于 16:9、1:1 或 9:16。Export resolution（Native、1080p，Pro 版可选 4K）会调整完成视频的尺寸。
Style preset（风格）一种视觉风格，例如 Cinematic realism 或 Anime / manga。请见风格。
Character（角色）最多勾选 4 位已保存的角色，或直接拖入一张参考照片。请见角色。

步骤 3：撰写描述（prompt）

描述您想看到的画面：主体、场景、光线、镜头。描述建议用英文，例如："a lone samurai on a misty mountain path at dawn, wide shot, soft light"（黎明时分雾中山路上的孤独武士，远景，柔和光线）。

切换到 Batch ✦ 可一次制作多个：在 Paste multiple prompts 每行粘贴一个描述，点击 Split into rows；或用 + Add row 逐行添加。

点击 Generate ✦。任务会进入 Dashboard 的队列，完成的作品会出现在 Gallery。

Advanced（高级，默认折叠）

  • GPU concurrency（仅图片与 Reel）：Off (safest)、Adaptive 或 Fast (risky)。让小型任务以略低的分辨率共用显卡。视频类任务总是单独运行。
  • Captions（字幕）与字幕样式（Reel 与音乐 MV）。标有 🎤 的样式会在念到每个字时高亮。
  • Brand kit（品牌套件）：您的 Logo、水印、片头与片尾。请见品牌套件。
  • Background music（背景音乐，适用于 Reel、视频、电影）：从音乐库挑选曲目，或用 Auto-match by keyword 按关键词自动配对，并设置 Music loudness (dB)。音乐库至少有一首曲目后才能勾选。
  • Auto-distribute on completion：任务完成后约 5 分钟内自动发布到已关联的账号。请见发布与定时发布。

查看进度

Dashboard 会显示队列、运行中任务的实时进度，以及最新的 12 个作品。每个任务都有 Cancel；若有失败，还有 Retry failed。重试的电影会从最后完成的场景继续，不必重头开始。
