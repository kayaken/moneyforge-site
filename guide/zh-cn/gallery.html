您的作品

Gallery 作品库

您制作的一切都会出现在 Gallery。在这里可以下载、重制、动画化、修正单一场景、调整成其他平台的尺寸或直接发布。

浏览与下载

可按 All、Images、Videos、Movies、Music videos 或 Reels 筛选。每张卡片都有收藏、下载、Remix、Animate、Distribute 和 Delete。使用选择模式可 Download selected（下载所选）或 Delete selected（删除所选）。删除的项目会移到 Settings 的 Trash（垃圾桶），可以还原。

Remix 与 Animate

Remix 会以相同设置重新打开 Create。Animate 会把图片变成以该图片开头的视频。

修正单一场景

电影、音乐 MV 和 Reel：打开作品，点击 Scenes。修改某个场景的描述（Reel 还可修改旁白），再点击 Regenerate this scene。只会重做那一个场景；音乐、字幕和品牌元素会重新应用到完成的视频上。

平台版本

Repurpose → Create platform variant 会为其他平台裁剪出一份副本，并保持脸部在画面中。太长的视频会修剪到平台上限：YouTube Shorts 60 秒、Instagram 与 Facebook 90 秒、X 140 秒、TikTok 600 秒。

从 Gallery 发布

Distribute 会打开发布表单：选择平台、标题、说明（会建议 AI 撰写的文案）、隐私设置，再点击 Post。请见发布与定时发布。
