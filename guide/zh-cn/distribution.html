发布

发布与定时发布

关联您自己的账号一次之后，就能从 Gallery 发布、在任务完成时自动发布，或让系列按计划自动生成并发布。

关联账号

打开 Distribution，逐一关联各平台。登录是在平台自己的页面上进行，MoneyForge 不会看到您的密码。

平台说明
YouTube可上传为公开、不公开或私人。
Facebook发布到您管理的 Facebook 公共主页。
Instagram需要关联到 Facebook 公共主页的专业账号（商业或创作者账号），并需要公开隧道（见下方）。Instagram 没有私人或草稿帖子。
TikTok测试时可把帖子设为“Only Me（仅自己）”。
Pinterest正在等待 Pinterest 的开发者审核。
X通过 API 发帖时，X 会向账号收取每则帖子的费用。

公开隧道（Public tunnel）

Instagram（以及 Pinterest 视频）会从网址抓取您的视频，因此 MoneyForge 需要一个连到您电脑的临时公开链接。在 Distribution 发布到 Instagram 之前先点击 Start tunnel，完成后点击 Stop tunnel。启动前请先更改默认的 admin 密码。

发布

  • 从 Gallery：对任一作品点击 Distribute。
  • 自动发布：在 Create 的 Auto-distribute on completion 勾选平台。任务完成后约 5 分钟内就会发布。

定时发布系列（Auto-scheduler）

系列会自动撰写、生成并发布 Reel。在 Auto-scheduler 点击 + New series，设置主题类别、Series name（系列名称）、可选的 Topic（题目）、Cadence（频率：Twice daily、Daily、3x per week、Weekly）、Aspect ratio、Voice、Narration language 与 Auto-post to（自动发布到）。系列可随时暂停、继续或删除。

每个定时发布的 Reel 都会先通过内容安全检查，这需要 Gemini 密钥或免费的本地 AI 模型；两者都没有时，定时发布的 Reel 会被略过，而不会未经检查就发布。系列运行时，您的电脑必须保持开机。
