設定與疑難排解

金鑰、授權、備份，以及最常遇到的問題的解決方法。

Settings（設定）

  • License（授權）：Activate 啟用金鑰；換到新電腦前，先按 Deactivate this machine。
  • Change password：變更 MoneyForge 登入密碼。
  • Google Gemini API Key（選用）：更好的圖片評分、多角色一致性、腳本、翻譯，以及排程系列的安全檢查。自動設定下載的免費本機 AI 模型不需金鑰即可處理大部分項目。加入金鑰後，相關內容會傳送到 Google。
  • ElevenLabs API Key（選用）：自然語音、聲音庫與聲音克隆。請見聲音。
  • Data & Backup（資料與備份）：Backup now、Show in folder、Restore。
  • Trash（垃圾桶）：Restore all（全部還原）或 Empty trash permanently（永久清空）。
  • System（系統）：版本號碼與 Run system check（執行系統檢查）。

程式內的 Help 頁面也會回答最常見的問題。

疑難排解

出現「No GPU detected」或一切都非常慢

更新 NVIDIA 驅動程式並重新開機，再開啟 Setup。若 Setup 仍顯示沒有顯示卡，請按 Copy system info 並寄給客服。

影片、電影或 AI MV 一開始就失敗

檢查 Setup → Model files：影片模型（約 64 GB）必須完整下載。只有 12 GB 以上的顯示卡才會下載影片模型。

某個選項無法勾選（灰色）

背景音樂、音效、影片素材和白板選項，需要對應的素材庫至少有一個項目。有鎖頭圖示的選項需要 Pro。

「Generate script」顯示沒有設定 AI 文字服務

本機 AI 文字模型尚未下載完成。請在 Setup 頁面查看進度，或在 Settings 加入免費的 Gemini 金鑰。

Reel 被拒絕，顯示「reels need an AI text check」

原因相同：本機 AI 文字模型尚未就緒。請讓它在 Setup 頁面下載完成（若已關閉自動設定，請展開 Manual setup 並使用 Install local AI model server），或在 Settings 加入免費的 Gemini 金鑰。

旁白聽起來像機器人

那是 Windows 系統語音。沒有設定 ElevenLabs 金鑰，或所選的 ElevenLabs 聲音無法使用時，就會改用系統語音。請在 Settings 加入金鑰。

電影比我設定的短

每個電影任務最多製作 6 個 5 秒場景（約 30 秒）。請見製作較長的影片。

無法登入

新安裝時請使用 admin / moneyforge，或點 reset it 連結。Gumroad 的帳號密碼在這裡無法使用。嘗試太多次後，請等 15 分鐘或重新開機。

聯絡客服

請寄信到 support@moneyforgestudio.com（可用中文），附上 Setup → Copy system info 的內容，並簡單說明您做了什麼、發生了什麼。也可以使用客服頁面上的線上對話。
