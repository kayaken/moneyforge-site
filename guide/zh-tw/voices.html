聲音

聲音與聲音克隆

免費的系統語音可直接使用。想要自然的聲音或克隆自己的聲音，請加入 ElevenLabs 金鑰。

免費的 Windows 系統語音

開啟 Voices，在 Your Windows system voices (free, offline) 對任一語音按 + Add。Windows 可在「設定 → 時間與語言 → 語音 → 新增語音」加入更多語音，包括中文語音。

加入 ElevenLabs 金鑰

ElevenLabs 是另外付費的語音服務。自然語音、聲音庫與聲音克隆都使用您自己的 ElevenLabs 帳號。

  1. 到 elevenlabs.io 註冊帳號，在 ElevenLabs 的設定中複製 API 金鑰。
  2. 在 MoneyForge 開啟 Settings → ElevenLabs API Key，貼上後按 Save key。

設定金鑰後，旁白文字（以及您上傳的聲音樣本）會傳送到 ElevenLabs 處理。

瀏覽 ElevenLabs 聲音庫

在 Voices 頁面，Browse ElevenLabs voice library 可搜尋數千種社群聲音，並依性別、年齡、口音篩選。按 + Add 即可使用，不需要錄音。

克隆自己的聲音

聲音克隆需要 ElevenLabs Starter 方案以上。

  1. 錄製 1 到 2 分鐘自然說話的聲音：安靜的房間，沒有音樂或回音，手機或耳機麥克風靠近嘴巴。存成 .mp3 或 .wav。
  2. 在 Voices 頁面的 Clone a new voice，輸入 Name（名稱）。
  3. Voice engine：選擇 ElevenLabs。
  4. Audio samples：選擇您的錄音檔（可選多個檔案）。
  5. Whose voice is this?：確認這是您自己的聲音，或已取得說話者的同意。每次都必須確認；未經同意克隆他人聲音在許多地區是違法的。
  6. 建立聲音。它會出現在清單中，以及 Create 頁面所有的 Voice 選單裡。

使用方式：在 Reel 的 Voice 選擇它，或把它設為角色的 Default voice。中文旁白請在 Narration language 選擇 Chinese。

1.0.3 版

1.0.3 版的安裝程式尚未提供免費的本機聲音克隆（不需 ElevenLabs），選項會顯示「not available in this version yet」。目前請使用 ElevenLabs 進行聲音克隆。
