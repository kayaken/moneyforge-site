發佈

發佈與排程

連結您自己的帳號一次之後，就能從 Gallery 發佈、在任務完成時自動發佈，或讓系列依排程自動生成並發佈。

連結帳號

開啟 Distribution，逐一連結各平台。登入是在平台自己的頁面上進行，MoneyForge 不會看到您的密碼。

平台說明
YouTube可上傳為公開、不公開或私人。
Facebook發佈到您管理的 Facebook 粉絲專頁。
Instagram需要連結到 Facebook 粉絲專頁的專業帳號（商業或創作者帳號），並需要公開通道（見下方）。Instagram 沒有私人或草稿貼文。
TikTok測試時可把貼文設為「Only Me（僅自己）」。
Pinterest正在等待 Pinterest 的開發者審核。
X透過 API 發文時，X 會向帳號收取每則貼文的費用。

公開通道（Public tunnel）

Instagram（以及 Pinterest 影片）會從網址抓取您的影片，因此 MoneyForge 需要一個連到您電腦的臨時公開連結。在 Distribution 發佈到 Instagram 之前先按 Start tunnel，完成後按 Stop tunnel。啟動前請先更改預設的 admin 密碼。

發佈

  • 從 Gallery：對任一作品按 Distribute。
  • 自動發佈：在 Create 的 Auto-distribute on completion 勾選平台。任務完成後約 5 分鐘內就會發佈。

自動排程系列（Auto-scheduler）

系列會自動撰寫、生成並發佈 Reel。在 Auto-scheduler 按 + New series，設定主題類別、Series name（系列名稱）、可選的 Topic（題目）、Cadence（頻率：Twice daily、Daily、3x per week、Weekly）、Aspect ratio、Voice、Narration language 與 Auto-post to（自動發佈到）。系列可隨時暫停、繼續或刪除。

每支排程的 Reel 都會先通過內容安全檢查，這需要 Gemini 金鑰或免費的本機 AI 模型；兩者都沒有時，排程的 Reel 會被略過，而不會未經檢查就發佈。系列執行時，您的電腦必須保持開機。
