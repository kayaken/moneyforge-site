第一步

開始使用

從下載安裝檔到完成第一張圖片，大約一小時（大部分時間在下載）。

安裝前確認

  • Windows 10 或 11（64 位元）。
  • NVIDIA 顯示卡，建議 12 GB 顯示記憶體（RTX 3060 12 GB 或更好）。只做圖片的話 6 GB 即可。
  • 16 GB 記憶體；約 40 GB 可用空間，另加模型：圖片約 11 GB，影片另需約 64 GB。
  • 最新的 NVIDIA 驅動程式。若版本太舊，Setup 頁面會提示您。

1. 執行安裝程式

  1. 從 Gumroad 收據信件（「View content」）或 Gumroad 資料庫下載 MoneyForge_Setup.exe。
  2. 執行安裝。若出現 Windows SmartScreen，請按 More info（其他資訊），再按 Run anyway（仍要執行）。
  3. 保持勾選自動啟動 MoneyForge。MoneyForge 會以 Windows 服務在背景執行，並在瀏覽器中開啟。
  4. 安裝完成後，瀏覽器會自動開啟 Setup 頁面。
更新版本

直接把新版本安裝在舊版本上即可，帳號、密碼、授權、API 金鑰和您製作的內容都會保留，不需要先解除安裝。

2. 第一次登入

登入畫面是您電腦上的本機帳號，不是 Gumroad 帳號，MoneyForge 也不會寄送任何 Email。

  1. 使用帳號 admin、密碼 moneyforge 登入。
  2. 系統會要求您設定新密碼，請立即設定。

忘記密碼時，請點登入畫面上的 reset it 連結。輸入錯誤太多次會暫停登入最多 15 分鐘（重新開機也可解除）。

3. 完成 Setup 頁面

點左側選單的 Setup。它會自動偵測顯示卡、驅動程式和磁碟。請依序完成：

  1. 1. Generation Engine（生成引擎）：在 Install on 選擇磁碟，按 Install generation engine。約 3 到 4 GB，需 20 到 40 分鐘；中斷時再按一次即可續傳。
  2. 2. Character Consistency Module（角色一致性模組）：按下安裝。使用角色功能時需要。
  3. 3. Model files（模型檔）：按 Download image models（約 11 GB）。顯示卡 12 GB 以上時，再按 Download video models（約 64 GB）。影片、電影與 AI MV 都需要它。
  4. 4. Local AI Text Model（本機 AI 文字模型）：若已安裝免費的 Ollama 程式，按 Download local AI model。它可在本機評分圖片、撰寫腳本、翻譯並檢查 Reel 腳本，不需任何雲端服務。製作 Reel 需要它或 Gemini 金鑰（二擇一）。
請確認

影片模型很大。製作影片、電影或 AI MV 之前，請先確認 Download video models 已經下載完成。影片任務一開始就失敗時，請先檢查這一項。

4. 啟用授權

  1. 從 Gumroad 資料庫頁面複製您的授權金鑰（license key）。
  2. 開啟 Settings，貼到 License key，按 Activate。

每個授權可用於一台電腦。要換電腦時，請先在舊電腦的 Settings 按 Deactivate this machine。

5. 製作第一張圖片

在 Dashboard 的歡迎視窗按 Forge your first image →；或開啟 Create，按 ✦ Start from scratch，輸入描述（prompt，建議用英文），再按 Generate ✦。Dashboard 會顯示進度，完成的作品會出現在 Gallery。

需要協助

在 Setup 頁面按 Copy system info，貼到 Email 寄給 support@moneyforgestudio.com（可用中文）。內容包含顯示卡、記憶體、磁碟與安裝狀態，不含密碼、授權金鑰或個人檔案。
