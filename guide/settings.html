Settings and troubleshooting

Keys, license, backups and the fixes for the problems people hit most.

Settings

  • License: Activate a key, or Deactivate this machine before moving to a new computer.
  • Change password for the MoneyForge sign-in.
  • Google Gemini API Key (optional): better image scoring, multi-character consistency, scripts, translation and the scheduler's safety check. The free local AI model that automatic setup downloads covers most of these without a key. With a key, the relevant content is sent to Google.
  • ElevenLabs API Key (optional): natural voices, the voice library and voice cloning. See Voices.
  • Data & Backup: Backup now, Show in folder, Restore.
  • Trash: Restore all or Empty trash permanently.
  • System: version number and Run system check.

The in-app Help page answers the most common questions too.

Troubleshooting

"No GPU detected" or everything is very slow

Update your NVIDIA driver, restart the computer, then open Setup. If Setup still shows no graphics card, click Copy system info and email it to support.

A video, movie or AI music video fails straight away

Check Setup → Model files: the video models (about 64 GB) must be fully downloaded. They're only offered on 12 GB+ cards.

A checkbox is greyed out

Background music, sound effects, stock footage and whiteboard options need at least one item in that library. Controls with a padlock need Pro.

"Generate script" says no AI text backend is configured

The local AI text model hasn't finished downloading yet. Check its progress on the Setup page, or add a free Gemini key in Settings.

A reel is refused with "reels need an AI text check"

Same cause: the local AI text model isn't ready. Let it finish on the Setup page (if automatic setup was turned off, open Manual setup and use Install local AI model server), or add a free Gemini key in Settings.

Narration uses a robotic voice

That's the Windows system voice, used when no ElevenLabs key is set or the chosen ElevenLabs voice isn't available. Add your key in Settings.

My movie came out shorter than I asked

Each movie job makes up to 6 five-second scenes (about 30 seconds). See making a longer film.

Can't sign in

Use admin / moneyforge on a new install, or the reset it link. Your Gumroad login won't work here. After too many tries, wait 15 minutes or restart.

Contact support

Email support@moneyforgestudio.com with the text from Setup → Copy system info and a short description of what you did and what happened. Or use the chat on the support page.
